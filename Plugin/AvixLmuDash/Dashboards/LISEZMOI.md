# Dashboards

Mets ici tes dashboards `.simhubdash` avant de lancer `AvixInstaller.exe` : ils seront copiés dans
`SimHub\DashTemplates` (ceux déjà installés sont conservés).

Ils ne sont pas publiés sur GitHub : ce sont des dashboards d'autres auteurs.
Les noms attendus par les règles par défaut sont listés dans le README.
