# Polices

L'installeur copie ces polices dans `SimHub\DashFonts` et les installe dans Windows (compte courant).

Polices libres incluses : Roboto (Apache 2.0), Cascadia Code, Orbitron, Rajdhani, DM Sans (SIL OFL 1.1).
Ajoute ici les polices de tes dashboards (beaucoup sont commerciales et ne peuvent pas être publiées sur GitHub).
